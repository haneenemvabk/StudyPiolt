Build a polished iOS-first mobile application called StudyPilot.

StudyPilot is an AI-powered academic operating system for university students. Its purpose is not simply to be a to-do list or calendar. It should understand a student’s courses, syllabus, assignments, lectures, exams, available study time, and progress, then continuously create and adapt a realistic study plan.

The core experience should answer one question whenever the student opens the app:

“What should I do NOW?”

The application should feel modern, intelligent, minimal, fast, and trustworthy. It should be designed for university students and eventually published on the Apple App Store.

* I am using AI/vibe coding and I do not want to manually write code.

* If something is unclear, choose the simplest production-ready implementation.
* Build an actual functional application, not a static mockup.
* Prioritize the MVP and working functionality over unnecessary complexity.
* Use a clean architecture that can later scale.
* The app must be mobile-first and optimized for iPhone.

1. PRODUCT CONCEPT
    ==================================================

StudyPilot turns a student’s academic information into a dynamic plan.

The student can enter or import:

* University courses
* Course names
* Course schedules
* Syllabi
* Assignments
* Exams
* Lecture notes
* Lecture PDFs
* Available study hours
* Personal deadlines
* Study sessions
* Completed tasks

The AI analyzes this information and creates a personalized academic plan.

The plan must dynamically adapt when:

* A task is completed
* A task is missed
* An exam date changes
* An assignment deadline changes
* The student has less available time
* The student adds a new assignment
* The student adds new course material
* The student changes priorities

The application should not merely display information.

It should make intelligent recommendations.

9. AI PLANNER

This is the core AI functionality.

Create an AI planning engine that generates study sessions based on:

INPUTS:

* Courses
* Topics
* Tasks
* Deadlines
* Exams
* Available hours
* Preferred study times
* Estimated task duration
* Difficulty
* Progress
* Previous completion behavior

OUTPUT:
A daily and weekly study plan.

The AI should prioritize:

1. Urgent deadlines
2. Upcoming exams
3. Incomplete high-priority assignments
4. Weak or incomplete topics
5. Consistent review
6. Available study time

Avoid unrealistic schedules.

Never schedule more study time than the user has declared available.

If there is insufficient time to complete everything, clearly communicate the conflict.

Example:

“You have 7 hours of work remaining but only 4 available study hours before your exam.”

Then suggest what should be prioritized and explain why.
